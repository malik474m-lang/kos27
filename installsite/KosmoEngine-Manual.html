2. Установка системы

2.1. Подготовка

  1. Создайте домен или поддомен на хостинге
  2. Создайте базу данных MySQL в панели хостинга
  3. Убедитесь, что PHP версия 8.1 или выше
  4. Убедитесь, что mod_rewrite включён

2.2. Загрузка установщика

Загрузите файл install.php из папки installsite/ в корневую директорию домена через FTP или файловый менеджер хостинга.

Установщик содержит все файлы проекта внутри себя (~1.3 МБ). Больше ничего загружать не нужно.

2.3. Запуск установки

  1. Откройте в браузере: https://ваш-домен.ru/install.php
  2. Система проверит требования (PHP, MySQL, cURL и т.д.)
  3. Заполните форму:
    • База данных: хост, имя БД, пользователь, пароль
    • Администратор: логин и пароль (минимум 6 символов)
    • Сайт: название и URL (с https://)
  4. Нажмите «🚀 Установить»

2.4. После установки

⚠️ Обязательно удалите install.php!
Команда SSH: rm install.php
Или удалите через файловый менеджер хостинга.

Установщик создаёт:

  • Все файлы проекта (~200 PHP файлов)
  • .htaccess — роутинг и безопасность
  • .env — конфигурация подключения к БД
  • config.php — настроенный под ваш домен
  • 27 таблиц в базе данных
  • Демо-данные: 4 оффера, 6 тегов, 9 категорий, 15 городов

3. Активация лицензии

  1. Войдите в админку: https://ваш-домен.ru/admin/login
  2. После входа вас перенаправит на страницу лицензии: /admin/license
  3. Введите ключ лицензии (формат: XXXX-XXXX-XXXX-XXXX)
  4. Нажмите «Активировать лицензию»
Лицензия привязывается к домену при первой активации. Проверка происходит каждые 4 часа. Если сервер лицензий недоступен — сайт работает ещё 24 часа (grace period).

На странице лицензии доступны:

  • 🔄 Проверить — принудительная проверка лицензии
  • Удалить — удалить лицензию (сайт перестанет работать)

4. Первые шаги после установки

  1. Смените пароль: Шапка админки → 🔑 Пароль
  2. Включите 2FA: Шапка → 🔐 2FA → отсканируйте QR-код
  3. Настройте сайт: Вкладка «⚙️ Настройки» — название, URL, логотип, Yandex Metrika, Google Analytics
  4. Добавьте реальные офферы: Замените демо-предложения на настоящие с партнёрскими ссылками
  5. Настройте категории: Проверьте и настройте разделы сайта

5.2. Дополнительные поля

Внизу формы оффера доступны дополнительные поля для SEO и детальной информации:

  • Meta Title / Meta Description — для SEO страницы оффера
  • Документы, Требования, Преимущества — отображаются на странице оффера
  • О компании — описание МФО/банка
  • FAQ — вопросы и ответы (JSON формат)
  • Features — ключевые особенности (JSON)

5.3. Сортировка

Офферы отображаются на сайте в порядке сортировки. Используйте drag-and-drop в списке или поле «Порядок» в форме редактирования.

5.4. Привязка тегов

В форме оффера есть раздел «Теги» — отметьте галочками нужные теги (например, «Без отказа», «На карту»). Оффер будет показываться на соответствующих страницах тегов.

5.5. Массовые действия

Нажмите ☑ Выбрать → отметьте офферы → доступны действия: Включить, Выключить, Удалить.

6. Категории

Вкладка 📂 Категории — управление разделами сайта и навигацией.

  • Основные категории: Займы, Кредиты, Кредитные карты, Дебетовые карты
  • Инструменты: Калькулятор, Сравнение, Статьи, FAQ, Глоссарий

Для каждой категории настраиваются:

  • Название, slug (URL), иконка
  • H1, Meta Title, Meta Description — для SEO
  • SEO-текст — отображается на странице категории
  • Показ в шапке / в подвале
  • Раздел подвала: Продукты или Инструменты
  • Подкатегории (вложенность)

8. Статьи

Вкладка 📰 Статьи — блог и информационный раздел.

  • Создание: Заголовок, содержание (HTML), обложка, Meta Title/Description
  • Автогенерация 🤖: Генерация статей через Yandex GPT (требуется API-ключ в настройках)
  • Публикация: Чекбокс «Опубликовать» — неопубликованные статьи не видны на сайте
  • Meta 🤖: Автоматическая генерация Meta Title и Description по содержанию
Для автогенерации необходимо указать Yandex GPT API Key и Folder ID в настройках сайта.

9. Отзывы

Вкладка ⭐ Отзывы — отзывы на офферы.

  • Привязаны к конкретному офферу
  • Поля: автор, рейтинг (1-5), текст, плюсы, минусы
  • Автогенерация 🤖: Генерация отзывов через Yandex GPT
  • Модерация — можно скрыть отзыв

10. SEO городов

Вкладка 🏙️ SEO городов — уникальные тексты для страниц городов.

Города берутся из файла data/cities.php (~50 городов). Для каждого города генерируются SEO-тексты:

  • H1, Title, Meta Description
  • SEO-текст (уникальный для каждого города)
  • Генерация: шаблонная или через Yandex GPT

URL страниц: /zajmy/moskva, /kredity/sankt-peterburg и т.д.

11. Гео-редиректы

Вкладка 🌍 Гео-редиректы — перенаправление посетителей по странам.

  • Редирект для всех стран: все посетители перенаправляются на указанный URL
  • Исключения: страны, которые НЕ редиректятся (например, Россия)
  • Редирект для конкретной страны: отдельный URL для выбранной страны

12. Партнёрские ссылки

Вкладка 🔗 Ссылки — проверка работоспособности партнёрских ссылок.

  • Проверить все: проверяет HTTP-статус всех ссылок
  • Статусы: OK (зелёный), Ошибка (красный), Не проверен (жёлтый)
  • Показывает HTTP-код, финальный URL после редиректов, дату проверки

13. Статистика и аналитика

Вкладка 📊 Статистика — полная аналитика кликов и просмотров.

  • Реальное время: клики за 5 мин, за час, за сегодня
  • Счётчики: сегодня, неделя, месяц, всего
  • Графики: клики и просмотры по дням
  • Топ офферов: рейтинг по кликам с конверсией
  • UTM-источники: source, medium, campaign
  • По часам: распределение кликов в течение дня

Период можно выбрать: 7, 14, 30, 90 дней или год.

14. Воронка конверсий

Вкладка 🔻 Воронка — визуализация пути пользователя.

Для каждого оффера показывает: Просмотры → Клики → Конверсии (одобрения). Помогает найти узкие места.

15. Умный рейтинг

Вкладка 🧠 Рейтинг — автоматический рейтинг офферов на основе:

  • CTR (кликабельность)
  • Approval Rate (процент одобрения)
  • EPC (доход за клик)
  • Рейтинг и отзывы

Кнопка «Применить Smart Rating» автоматически пересортирует офферы.

16. A/B тесты

Вкладка 🧪 A/B тесты — тестирование кнопок оформления.

  • Создайте тест с вариантами кнопок (текст + цвет)
  • Система автоматически показывает разные варианты посетителям
  • Отслеживайте показы и клики для каждого варианта
  • Можно ограничить по категории офферов

17. Конверсии и Postback

Вкладка 💰 Конверсии — трекинг конверсий от партнёрских программ.

17.1. Postback URL

Настройте в партнёрской программе (например, Leads.su) URL для отправки postback:

https://ваш-сайт.ru/api/postback?click_id={click_id}&status={status}&payout={payout}&offer_id={offer_id}

17.2. Профили Postback

Создавайте профили для разных партнёрок. Каждый профиль содержит настройки маппинга параметров.

17.3. Таблица конверсий

Показывает: дату, оффер, статус (approved/rejected/pending), выплату, click_id.

18. Подписчики и рассылки

Вкладка 📬 Подписчики — email-маркетинг.

18.1. Подписчики

  • Собираются через форму в подвале сайта и popup
  • Можно включать/отключать подписку
  • Автоматический токен отписки

18.2. Рассылки

  • Создание: тема + HTML-содержание
  • {{offers}} — вставка карточек офферов с логотипами и кнопками
  • 🤖 Генерация: автоматическая генерация текста через Yandex GPT
  • Тестовая отправка: отправить на свой email для проверки
  • Массовая отправка: всем активным подписчикам
  • Лог отправки: статус каждого письма

19. Планировщик автогенерации

Вкладка ⏰ Планировщик — автоматическая генерация контента.

  • Настройте расписание генерации статей и отзывов
  • Указывается интервал (в часах) и количество
  • Работает через cron или внутренний таймер

20. Пакетная генерация

Вкладка 🤖 Пакетная — массовая генерация контента.

  • Генерация нескольких статей или отзывов за один раз
  • Выбор тематики и количества
  • Требуется Yandex GPT API Key

25. Здоровье сайта

Вкладка 🏥 Здоровье — диагностика системы.

  • Проверка подключения к БД
  • Наличие обязательных таблиц
  • Проверка офферов без ссылок
  • Битые партнёрские ссылки
  • Права на запись в директории

26. Безопасность

Вкладка 🔒 Безопасность — защита админки.

  • IP Whitelist: ограничение доступа к админке по IP
  • 2FA: двухфакторная авторизация (TOTP)
  • Защита от брутфорса: прогрессивная блокировка (5 попыток → 5 мин, 10 → 15 мин, 20 → 1 час)
  • Привязка сессии к IP
  • Лог входов: все попытки авторизации с IP и User-Agent

30. Часто задаваемые вопросы

Как сменить пароль администратора?

Шапка админки → 🔑 Пароль → введите текущий и новый пароль.

Как включить 2FA?

Шапка → 🔐 2FA → отсканируйте QR-код в Google Authenticator или Yandex.Key.

Как очистить кэш?

Шапка → 🗑 Сбросить кэш. Также: ⚡ API-кэш для обновления данных API.

Сайт показывает «Лицензия не активирована»

Войдите в /admin/login, затем перейдите на /admin/license и введите ключ.

500 ошибка после установки

Проверьте: версия PHP (нужна 8.1+), корректность данных в .env, наличие .htaccess.

Как добавить город для SEO?

Города хранятся в файле data/cities.php. Добавьте запись в массив.

Как настроить Postback?

Админка → Конверсии → внизу страницы будет URL для postback. Скопируйте его и вставьте в настройки партнёрской программы.
