================================================================================
1. ТРЕБОВАНИЯ
================================================================================

- PHP 7.4 или выше (рекомендуется PHP 8.0+)
- MySQL 5.7 или выше (или MariaDB 10.3+)
- Apache с mod_rewrite (или nginx)
- SSL-сертификат (HTTPS) — обязательно!

================================================================================
2. ПОДГОТОВКА ХОСТИНГА
================================================================================

2.1. Создайте поддомен serv.kosmozaim.ru в панели хостинга

2.2. Директория поддомена должна быть пустой:
     ~/domains/serv.kosmozaim.ru/

================================================================================
3. ЗАГРУЗКА ФАЙЛОВ
================================================================================

ВАРИАНТ А: Скопировать из основного репозитория

    Если kosmozaim.ru уже настроен через git:
    
    cp -r ~/domains/kosmozaim.ru/license-server/* ~/domains/serv.kosmozaim.ru/

ВАРИАНТ Б: Через FTP

    Скачайте папку license-server/ из GitHub и загрузите 
    её содержимое в корень serv.kosmozaim.ru

ИТОГОВАЯ СТРУКТУРА:
    
    serv.kosmozaim.ru/
    ├── index.php
    ├── config.php
    ├── database.sql
    ├── .htaccess
    ├── .env              <-- создать!
    ├── .env.example
    ├── _admin/
    │   ├── router.php
    │   ├── login.php
    │   └── dashboard.php
    └── _api/
        └── ...

================================================================================
4. НАСТРОЙКА БАЗЫ ДАННЫХ
================================================================================

4.1. Создайте новую базу данных MySQL в панели хостинга:
     
     Имя БД:      partnerka72_license (или любое другое)
     Пользователь: partnerka72_lic
     Пароль:      сгенерируйте сложный пароль
     Права:       ALL PRIVILEGES

4.2. Импортируйте структуру через phpMyAdmin:
     
     - Откройте phpMyAdmin
     - Выберите созданную базу данных
     - Вкладка "Импорт"
     - Выберите файл database.sql
     - Нажмите "Выполнить"

     Или через SSH:
     mysql -u partnerka72_lic -p partnerka72_license < database.sql

4.3. Проверьте таблицы:
     admins, plans, licenses, license_checks, login_attempts, audit_log

================================================================================
5. НАСТРОЙКА КОНФИГУРАЦИИ
================================================================================

5.1. Создайте файл .env:

     cp .env.example .env

5.2. Отредактируйте .env:

     DB_HOST=localhost
     DB_NAME=partnerka72_license
     DB_USER=partnerka72_lic
     DB_PASS=ваш_пароль_базы_данных
     API_SECRET=случайная_строка_минимум_32_символа

     Для генерации API_SECRET используйте:
     https://passwordsgenerator.net/ (64 символа, без спецсимволов)

5.3. Установите права:
     
     chmod 600 .env

================================================================================
6. ПЕРВЫЙ ВХОД
================================================================================

6.1. Откройте: https://serv.kosmozaim.ru/admin

6.2. Данные для входа:
     
     ╔═══════════════════════════════╗
     ║  Логин:   admin               ║
     ║  Пароль:  admin123            ║
     ╚═══════════════════════════════╝

6.3. ⚠️ СРАЗУ ПОСЛЕ ВХОДА:
     
     1) Нажмите "🔑 Пароль" — смените на сложный (12+ символов)
     2) Нажмите "🔒 2FA" — включите двухфакторную авторизацию
     3) Сохраните резервные коды в надёжном месте!

================================================================================
7. НАСТРОЙКА БЕЗОПАСНОСТИ
================================================================================

7.1. Проверьте HTTPS
     https://serv.kosmozaim.ru должен открываться без ошибок

7.2. Проверьте защиту файлов
     https://serv.kosmozaim.ru/.env — должна быть ошибка 403

7.3. Включите 2FA
     Обязательно! Без 2FA админка уязвима.

================================================================================
8. ПРОВЕРКА РАБОТЫ
================================================================================

8.1. Админка работает:
     https://serv.kosmozaim.ru/admin → видите дашборд

8.2. API отвечает (проверка через браузер или curl):
     
     POST https://serv.kosmozaim.ru/api/check
     {"license_key":"TEST","domain":"test.com"}
     
     Ответ: {"valid":false,"code":"INVALID_KEY"}

8.3. Создайте тестовую лицензию:
     - Лицензии → + Создать → Trial → Создать
     - Скопируйте ключ

================================================================================
9. ВОЗМОЖНЫЕ ПРОБЛЕМЫ
================================================================================

ПРОБЛЕМА: 500 Internal Server Error
РЕШЕНИЕ: Проверьте error_log, права на файлы (644), .htaccess

ПРОБЛЕМА: Ошибка подключения к БД  
РЕШЕНИЕ: Проверьте данные в .env, права пользователя БД

ПРОБЛЕМА: 404 на /admin
РЕШЕНИЕ: Включите mod_rewrite, проверьте .htaccess

ПРОБЛЕМА: Забыли пароль или 2FA
РЕШЕНИЕ: В phpMyAdmin выполните:
         UPDATE admins SET password_hash='$2y$10$N9qo8uLOickgx2ZMRZoMy.MqrqRqEuBv1WPn4MZKNqNxdPaXmNeDy', totp_enabled=0 WHERE id=1;
         (сбросит пароль на admin123)
