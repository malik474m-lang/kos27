================================================================
  НАСТРОЙКА ПОЧТЫ kosmozaim.ru НА ХОСТИНГЕ JINO
  SPF / DKIM / DMARC / BIMI
================================================================

Цель: письма от info@kosmozaim.ru не попадают в спам,
      иконка отправителя отображается в почтовых клиентах.


================================================================
  ЭТАП 1: SPF и DKIM (5 минут)
================================================================

1. Зайди в панель Jino: https://cp-mail.jino.ru
2. Раздел: Почта -> Управление -> Почтовые ящики
3. Найди домен kosmozaim.ru
4. Рядом с доменом будут кнопки SPF и DKIM
5. Нажми на каждую -> включи переключатели
6. Записи добавятся автоматически в DNS

Если домен НЕ делегирован на Jino:
- Нажми SPF/DKIM -> скопируй предложенные записи
- Добавь их вручную у регистратора домена


================================================================
  ЭТАП 2: DMARC (5 минут)
================================================================

1. Зайди: Домены -> Управление -> kosmozaim.ru -> DNS
2. Нажми "Новая DNS-запись"
3. Заполни:

   Тип:      TXT
   Имя:      _dmarc
   Значение: v=DMARC1; p=quarantine; rua=mailto:info@kosmozaim.ru; ruf=mailto:info@kosmozaim.ru; fo=1; adkim=s; aspf=s; pct=100

4. Сохрани

Пояснение:
- p=quarantine -- подозрительные письма в спам (мягкий режим)
- rua -- отчёты об отправках на info@kosmozaim.ru
- pct=100 -- политика для 100% писем

Через 1-2 недели, когда убедишься что все работает,
можно усилить до p=reject:

   v=DMARC1; p=reject; rua=mailto:info@kosmozaim.ru; ruf=mailto:info@kosmozaim.ru; fo=1; adkim=s; aspf=s; pct=100


================================================================
  ЭТАП 3: ПРОВЕРКА (после этапов 1-2)
================================================================

Подожди 1-2 часа после добавления записей, затем проверь:

1. SPF:
   https://mxtoolbox.com/spf.aspx
   Введи: kosmozaim.ru -> должно быть "SPF Record Found"

2. DKIM:
   https://mxtoolbox.com/dkim.aspx
   Введи домен и селектор (узнаешь из панели Jino)

3. DMARC:
   https://mxtoolbox.com/dmarc.aspx
   Введи: kosmozaim.ru -> должно быть "DMARC Record Found"

4. Комплексная проверка:
   https://www.mail-tester.com/
   Отправь тестовое письмо на указанный адрес -> получишь оценку


================================================================
  ЭТАП 4: BIMI -- иконка отправителя (15 минут)
================================================================

BIMI показывает логотип рядом с именем отправителя в почтовом
клиенте (Gmail, Yahoo, Apple Mail).

Требования:
- DMARC должен быть настроен (этап 2)
- Логотип в формате SVG Tiny PS
- DNS-запись BIMI

Шаг 1: Подготовь SVG-логотип

- Формат: SVG Tiny 1.2 Portable/Secure
- Размер: квадратный, до 32 KB
- Фон: непрозрачный (не прозрачный!)
- Без анимации, без скриптов

Можно сконвертировать через:
https://bimigroup.org/bimi-generator/

Готовый файл залей на сервер:
https://kosmozaim.ru/images/bimi.svg

Шаг 2: Добавь DNS-запись BIMI

1. Домены -> Управление -> kosmozaim.ru -> DNS
2. Новая DNS-запись:

   Тип:      TXT
   Имя:      default._bimi
   Значение: v=BIMI1; l=https://kosmozaim.ru/images/bimi.svg;

Шаг 3: Проверь

https://bimigroup.org/bimi-generator/
Введи kosmozaim.ru -> проверит наличие записи и SVG


================================================================
  ЭТАП 5: VMC/CMC СЕРТИФИКАТ (опционально)
================================================================

Для Gmail и Apple Mail нужен сертификат:

VMC (Verified Mark Certificate):
- Нужен зарегистрированный товарный знак
- Стоимость: 749-1750 USD в год
- Выдают: DigiCert, Entrust
- Дает синюю галочку в Gmail

CMC (Common Mark Certificate):
- НЕ нужен товарный знак
- Нужно доказать использование логотипа 12+ месяцев
- Стоимость: 650-1100 USD в год
- Показывает логотип в Gmail без синей галочки

Без сертификата BIMI работает в:
- Yahoo Mail -- да
- AOL -- да
- Fastmail -- да
- Gmail -- НЕТ (нужен VMC/CMC)
- Apple Mail -- НЕТ (нужен VMC)
