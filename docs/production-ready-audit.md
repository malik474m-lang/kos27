# Production-ready audit

Документ для финальной оценки готовности проекта к стабильной эксплуатации.

## 1. Инфраструктура

### Сервер
- [ ] PHP 8.1+
- [ ] cURL включён
- [ ] OpenSSL включён
- [ ] mbstring включён
- [ ] cron доступен
- [ ] HTTPS работает стабильно

### Доступы на запись
- [ ] `data/`
- [ ] `data/backups/`
- [ ] `data/page_cache/`
- [ ] `data/api_cache/`
- [ ] `images/`
- [ ] `images/articles/`

## 2. База данных

- [ ] база подключается без ошибок
- [ ] все основные таблицы существуют
- [ ] миграции применены
- [ ] есть резервная копия БД
- [ ] размер БД контролируется в Мониторинге

## 3. Безопасность

- [ ] пароль администратора изменён
- [ ] 2FA включена
- [ ] IP whitelist настроен (если нужен)
- [ ] нет стандартного `admin123`
- [ ] SMTP-данные не торчат публично
- [ ] ключи Google / Яндекс сохранены вне git

## 4. Почта

- [ ] SMTP настроен
- [ ] тест письма проходит
- [ ] форма обратной связи отправляет письма
- [ ] подписка на рассылку работает
- [ ] SPF / DKIM / DMARC настроены

## 5. SEO

- [ ] robots.txt доступен
- [ ] sitemap.xml доступен
- [ ] llms.txt доступен
- [ ] SEO-аудит отрабатывает
- [ ] meta-теги заполняются
- [ ] city SEO / city+tag SEO генерируются
- [ ] Google Search Console подключён
- [ ] Google Indexing API подключён
- [ ] Яндекс.Вебмастер подключён

## 6. Контент

- [ ] статьи создаются вручную
- [ ] статьи создаются автоматически
- [ ] у статей генерируются обложки
- [ ] FAQ создаются для офферов
- [ ] качество контента анализируется
- [ ] улучшение текста работает

## 7. Аналитика

- [ ] статистика кликов работает
- [ ] финансовая аналитика работает
- [ ] воронка по офферам работает
- [ ] debug воронки показывает реальные данные
- [ ] позиции Яндекс загружаются
- [ ] позиции Google загружаются

## 8. Партнёрская модель

- [ ] партнёрские ссылки проверяются
- [ ] postback-конверсии записываются
- [ ] approval rate считается
- [ ] EPC считается
- [ ] отклонённые конверсии видны

## 9. Автоматизация

- [ ] cron настроен
- [ ] scheduler активен
- [ ] автоотзывы создаются
- [ ] автостатьи создаются
- [ ] maintenance-cron запускается
- [ ] автоиндексация URL работает

## 10. Мониторинг

- [ ] Мониторинг открыт и читаем
- [ ] нет critical/fatal ошибок
- [ ] ложные warning отфильтрованы
- [ ] видно почту, cron, SEO-интеграции, генерацию картинок

## 11. Риски перед production

Считать проект не полностью production-ready, если:
- падает вход в админку;
- ломается layout или роутинг;
- не работает SMTP;
- не работают SEO/API-интеграции;
- нет бэкапов;
- лог ошибок регулярно пополняется критическими ошибками.

## 12. Итоговая оценка

### Уровень A — готов к стабильной эксплуатации
- все основные модули работают;
- есть бэкапы;
- мониторинг чистый;
- SMTP и индексация настроены;
- критичных ошибок нет.

### Уровень B — можно работать, но нужны доработки
- ядро работает;
- часть интеграций нестабильна;
- есть warning/единичные ошибки;
- документация частично готова.

### Уровень C — технически мощно, но рискованно
- много функционала;
- нестабильная эксплуатация;
- повторяются падения/ошибки;
- высокая зависимость от автора проекта.

## 13. Рекомендация по аудиту

Проводить этот audit:
- после больших релизов;
- раз в неделю на активном проекте;
- перед передачей проекта третьему лицу;
- перед продажей проекта.
