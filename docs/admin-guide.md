# Руководство по админке KosmoEngine

## 1. Общая идея

Админка проекта работает как единый SPA-интерфейс на странице `/admin`.
Все данные загружаются через внутренние API-эндпоинты `/api/admin/...`.

## 2. Основные разделы

### Настройки
Содержит:
- название сайта;
- URL сайта;
- логотип и favicon;
- YandexGPT / YandexART;
- провайдер генерации картинок статей;
- SMTP;
- email обратной связи;
- аналитику.

### Предложения
Управление офферами:
- добавление и редактирование офферов;
- описание, лимиты, срок, ПСК, ставка;
- логотип и партнёрская ссылка;
- теги;
- дополнительные поля;
- качество описания;
- FAQ;
- клики за 30 дней и за всё время.

### Статьи
- создание вручную;
- автогенерация;
- мета-теги;
- обложка;
- статус публикации;
- статус качества контента;
- score;
- улучшение текста.

### Теги
- slug, H1, description, meta;
- SEO-текст;
- поисковые запросы;
- автогенерация SEO;
- автофичи;
- эмодзи-иконка;
- привязка офферов.

### Города
- ручное добавление / удаление / редактирование;
- slug;
- регион;
- предложный падеж.

### SEO городов
Два блока:
- SEO-тексты для городов;
- SEO-тексты для страниц `город + тег`.

Есть:
- генерация по шаблону;
- генерация через YandexGPT;
- очистка markdown / HTML;
- выбор scope по городам;
- фильтры.

### Индексация
Содержит:
- sitemap / robots / llms;
- экспорт URL;
- Google Indexing API;
- Яндекс.Вебмастер API;
- проверку страниц;
- SEO-аудит.

### Позиции
Показывает:
- запросы из Яндекс.Вебмастера;
- запросы из Google Search Console;
- позиции, показы, клики, CTR;
- воронку `просмотр → клик → конверсия`;
- позиции по страницам.

### Воронка
Отдельный блок по офферам:
- просмотры;
- клики;
- одобрено;
- rejected;
- pending;
- CTR;
- CR;
- approval rate;
- EPC;
- доход.

Есть debug-проверка логики по офферу.

### Партнёрские ссылки
- массовая проверка;
- проверка одной ссылки;
- обработка антибот-защиты партнёрок;
- статусы OK / OK* / Ошибка.

### Финансовая аналитика
- доход по офферам;
- доход по категориям;
- партнёрки;
- источники;
- динамика;
- отклонённые конверсии.

### Розыгрыши
- создание конкурса;
- даты старта/финиша;
- розыгрыш в эфире;
- процент призового фонда;
- ограничение по одному офферу или всем;
- участники;
- CSV;
- статистика;
- фрод-сигналы;
- ручной запуск победителя.

### Мониторинг
- почта;
- внешние сервисы;
- SEO-интеграции;
- 2FA;
- планировщик;
- бэкапы;
- БД;
- PHP;
- кэш;
- последние ошибки.

## 3. Работа с контентом

### Статьи
Рекомендуемый процесс:
1. создать или сгенерировать статью;
2. проверить score;
3. использовать кнопки:
   - `🧪 Качество`
   - `✨ Улучшить`
   - `🎯 До 80+`
   - `🚀 До 90+`
   - `🧹 Только мусор`
4. проверить мета-теги;
5. опубликовать.

### Теги
Рекомендуемый процесс:
1. указать название;
2. выбрать категорию;
3. сгенерировать SEO через `✨ SEO`;
4. проверить/улучшить текст;
5. сгенерировать фичи;
6. привязать офферы.

### Офферы
Рекомендуемый процесс:
1. заполнить финансовые поля;
2. вставить партнёрскую ссылку;
3. улучшить описание;
4. привязать теги;
5. сгенерировать FAQ.

## 4. Кнопки качества контента

### 🧪 Качество
Показывает:
- score;
- количество слов/предложений/абзацев;
- список проблем;
- рекомендации.

### ✨ Улучшить
Один проход улучшения текста.

### 🎯 До 80+
Несколько проходов улучшения до score 80+.

### 🚀 До 90+
Несколько проходов улучшения до score 90+.

### 🧹 Только мусор
Убирает markdown / HTML-мусор без сильного переписывания смысла текста.

## 5. 2FA

### Включение
1. Нажать `🔐 2FA` в шапке.
2. Нажать `Включить 2FA`.
3. Отсканировать QR.
4. Ввести 6-значный код.
5. Сохранить резервные коды.

### Отключение
Через ту же панель 2FA, уже без повторного ввода пароля — достаточно активной админ-сессии.

## 6. FAQ для офферов

Есть два режима:
- вручную по каждому офферу;
- массово для всех офферов без FAQ.

Используется YandexGPT + fallback.

## 7. Работа с индексацией

### Google
- загрузка service account JSON;
- тест авторизации;
- отправка одного URL;
- отправка новых URL пачкой.

### Яндекс
- OAuth token + user_id + host_id;
- тест авторизации;
- переобход одного URL;
- переобход новых URL пачкой.

## 8. Мониторинг изображений статей

В Мониторинге отображается:
- выбранный провайдер;
- prompt;
- последние попытки генерации;
- requested provider / actual provider;
- причина fallback или ошибки.

## 9. Полезные сценарии работы

### Если текст плохой
- проверить `Качество`;
- сначала попробовать `🧹 Только мусор`;
- затем `🎯 До 80+`;
- если нужен сильный результат — `🚀 До 90+`.

### Если не индексируется страница
- открыть `Индексация`;
- проверить robots/sitemap/llms;
- отправить URL в Google / Яндекс;
- проверить `Позиции` и `Мониторинг`.

### Если что-то работает нестабильно
- открыть `Мониторинг`;
- посмотреть ошибки;
- проверить почту, cron, внешние сервисы.

## 10. Что особенно важно не забывать

- после крупных изменений иногда полезно сбрасывать кэш;
- после настройки SMTP — отправить тестовое письмо;
- после подключения индексации — выполнить тест авторизации;
- перед публикацией AI-контента — проверять качество и адекватность текста.
