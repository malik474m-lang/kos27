# Production-ready аудит проекта

## 1. Цель документа

Этот чек-лист нужен, чтобы убедиться, что проект готов к:
- стабильной работе на продакшене;
- передаче другому разработчику;
- продаже проекта.

## 10. Периодичность проверки

Рекомендуется проходить этот аудит:
- перед передачей проекта;
- перед продажей;
- раз в 1-2 месяца для поддержки;
- после крупных изменений.
