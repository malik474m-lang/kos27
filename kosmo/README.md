# KosmoEngine Installer

## 🚀 Автономный установщик CMS для финансовых сайтов

**Версия:** 1.1.0

> ⚠️ **Требуется лицензия!** Для работы сайта необходимо активировать лицензию. Получите ключ у администратора системы.

### 📋 Возможности системы

- Агрегатор финансовых предложений (займы, кредиты, карты)
- AI-генерация контента (статьи, отзывы, SEO-тексты)
- Продвинутая админка с единым SPA-интерфейсом
- A/B тестирование кнопок
- SEO-инструменты и автоиндексация
- Аналитика воронки и конверсий
- Рассылки и подписчики
- Розыгрыши с призовым фондом
- Postback интеграция с партнёрками

### ⚙️ Системные требования

- **PHP:** 8.0+
- **MySQL:** 5.7+ / MariaDB 10.3+
- **Расширения PHP:** pdo, pdo_mysql, mbstring, json, curl, openssl
- **Веб-сервер:** Apache с mod_rewrite или Nginx

### 📦 Установка

1. **Загрузите файл `install.php`** в корень вашего домена
2. **Откройте в браузере:** `https://ваш-домен.ru/install.php`
3. **Следуйте шагам установщика:**
   - Проверка системных требований
   - Настройка базы данных
   - Создание администратора
4. **После установки:**
   - Войдите в админку `/admin`
   - Активируйте лицензию (ключ получите у администратора)
   - Удалите `install.php`

### 🔐 Активация лицензии

После установки сайт не будет работать без лицензии:

1. Войдите в админку: `https://ваш-домен.ru/admin`
2. Вас перенаправит на страницу активации
3. Введите ключ лицензии в формате `XXXX-XXXX-XXXX-XXXX`
4. После активации сайт заработает

**Получить лицензию:** обратитесь к администратору системы.

### 🔧 Настройка Cron

После активации добавьте в crontab:

```bash
# Автогенерация статей (раз в 6 часов)
0 */6 * * * curl -s "https://ваш-домен.ru/api/cron-generate?secret=CRON_SECRET&type=article"

# Автогенерация отзывов (раз в 4 часа)
0 */4 * * * curl -s "https://ваш-домен.ru/api/cron-generate?secret=CRON_SECRET&type=review"

# Обслуживание (раз в день в 3:00)
0 3 * * * php /path/to/site/cron/maintenance-cron.php
```

CRON_SECRET находится в файле `.env` после установки.


### 🤖 AI-генерация (опционально)

Для работы AI-генерации контента:

1. Откройте админку → Настройки
2. Введите ключи:
   - **YandexGPT API Key** — для генерации текстов
   - **Yandex Folder ID** — ваш folder в Яндекс.Облаке

### 🔒 Безопасность

- Двухфакторная авторизация (2FA) в админке
- IP-whitelist для админки
- Аудит-лог всех действий
- Защита от brute-force
- Проверка лицензии каждые 4 часа
