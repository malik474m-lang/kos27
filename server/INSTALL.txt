1. ТРЕБОВАНИЯ
================================================================

  - PHP 8.0 или выше
  - MySQL 5.7+ или MariaDB 10.3+
  - Расширения PHP: pdo_mysql, openssl, json, mbstring
  - Домен с SSL-сертификатом (https)
  - Поддержка .htaccess (mod_rewrite)

2. ПОДГОТОВКА ХОСТИНГА
================================================================

Шаг 2.1. Создать поддомен
  В панели хостинга (Jino) создать поддомен: serv.kosmozaim.ru
  Корневая папка: ~/domains/serv.kosmozaim.ru/

Шаг 2.2. Создать базу данных
  В phpMyAdmin или панели хостинга создать новую БД.
  Например: partnerka72_license
  Запомнить: имя БД, пользователь, пароль.

Шаг 2.3. Скачать файлы
  Перейти в папку проекта и скопировать файлы сервера:

  cd ~/domains/kosmozaim.ru/
  git pull origin main
  cp -r license-server/* ~/domains/serv.kosmozaim.ru/
  cp server/install.php ~/domains/serv.kosmozaim.ru/

  После копирования в ~/domains/serv.kosmozaim.ru/ должны быть:
    install.php
    index.php
    config.php     (шаблон, будет перезаписан установщиком)
    .htaccess
    api/
      activate.php
      verify.php
      deactivate.php
      heartbeat.php
    admin/
      index.php
      api.php


================================================================
3. УСТАНОВКА ЧЕРЕЗ ВЕБ-ИНТЕРФЕЙС (рекомендуется)
================================================================

Шаг 3.1. Открыть в браузере:
  https://serv.kosmozaim.ru/install.php

Шаг 3.2. Проверить что все требования выполнены (зелёные галочки)

Шаг 3.3. Заполнить форму:
  - Хост MySQL:         localhost
  - Имя базы данных:    partnerka72_license (ваша БД)
  - Порт:               3306
  - Пользователь MySQL: partnerka72 (ваш пользователь)
  - Пароль MySQL:       ваш пароль
  - Логин администратора: admin (или свой)
  - Пароль администратора: придумайте надёжный (мин. 6 символов)

Шаг 3.4. Нажать "Установить"

Шаг 3.5. Если всё успешно — вы увидите зелёное сообщение.
  Установщик автоматически:
  - Создаст все таблицы в базе данных
  - Создаст аккаунт администратора
  - Сгенерирует уникальные ключи шифрования
  - Запишет рабочий config.php

Шаг 3.6. ОБЯЗАТЕЛЬНО удалить install.php:
  Через SSH:   rm ~/domains/serv.kosmozaim.ru/install.php
  Или в файловом менеджере хостинга.

4. УСТАНОВКА ЧЕРЕЗ SSH
================================================================

  cd ~/domains/serv.kosmozaim.ru/

  php install.php \
    --db-host=localhost \
    --db-name=partnerka72_license \
    --db-user=partnerka72 \
    --db-pass=ваш_пароль \
    --admin-user=admin \
    --admin-pass=ваш_пароль_админа

  Затем удалить:
  rm install.php

5. ПРОВЕРКА РАБОТОСПОСОБНОСТИ
================================================================

Шаг 5.1. Проверить статус сервера:
  Открыть: https://serv.kosmozaim.ru/
  Должен ответить JSON:
  {"server":"KZM License Server","version":"1.0","status":"online",...}

Шаг 5.2. Проверить админку:
  Открыть: https://serv.kosmozaim.ru/admin
  Войти с логином/паролем, указанным при установке.

Шаг 5.3. Создать тестовую лицензию:
  В админке нажать "+ Создать"
  - Домен: kosmozaim.ru
  - План: basic
  - Нажать "Создать"
  - Скопировать сгенерированный ключ KZM-XXXXXX-XXXXXX-XXXXXX-XXXXXX

Шаг 5.4. Проверить API через curl:
  curl -s https://serv.kosmozaim.ru/api/verify \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"license_key":"KZM-XXXXXX-...", "domain":"kosmozaim.ru"}'

6. БЕЗОПАСНОСТЬ ПОСЛЕ УСТАНОВКИ
================================================================

  ✅ Удалить install.php
  ✅ Удалить database.sql (если загружали отдельно)
  ✅ Проверить что config.php недоступен по URL:
     https://serv.kosmozaim.ru/config.php → должен вернуть 403
  ✅ Проверить что .htaccess работает (mod_rewrite включён)
  ✅ Сменить пароль админа если нужно (через /admin)
  ✅ Настроить SSL если ещё не настроен

  Ключи шифрования хранятся в config.php:
  - LICENSE_SIGN_KEY    — подпись ответов (HMAC-SHA256)
  - LICENSE_ENCRYPT_KEY — шифрование токенов (AES-256-CBC)
  - LICENSE_SALT        — соль для хэширования
  - ADMIN_API_TOKEN     — токен для API админки

  Все ключи генерируются автоматически при установке.
  Не передавайте их третьим лицам.

7. УПРАВЛЕНИЕ ЛИЦЕНЗИЯМИ
================================================================

Через веб-админку: https://serv.kosmozaim.ru/admin

Возможности:
  - Создание лицензий с привязкой к домену
  - Редактирование (домен, план, срок, статус)
  - Приостановка / отзыв лицензии
  - Просмотр логов по каждой лицензии
  - Статистика: активные, истёкшие, отказы

Форматы лицензионных ключей:
  KZM-XXXXXX-XXXXXX-XXXXXX-XXXXXX (24 hex символа)

Планы:
  - trial      — пробный период
  - basic      — базовый
  - pro        — расширенный
  - enterprise — полный доступ

Статусы:
  - active     — активна
  - suspended  — приостановлена (временно)
  - expired    — истёк срок
  - revoked    — отозвана навсегда

8. API СЕРВЕРА
================================================================

Все запросы: POST, Content-Type: application/json

POST /api/activate
  Тело: {"license_key":"KZM-...", "domain":"site.com"}
  Ответ: {"valid":true, "license":{...}, "activation_token":"..."}
  Привязывает лицензию к домену.

POST /api/verify
  Тело: {"license_key":"KZM-...", "domain":"site.com"}
  Ответ: {"valid":true, "license":{plan, status, features, days_left}}
  Проверяет что лицензия действительна для домена.

POST /api/heartbeat
  Тело: {"license_key":"KZM-...", "domain":"site.com"}
  Ответ: {"valid":true}
  Фоновая проверка (из крона).

POST /api/deactivate
  Тело: {"license_key":"KZM-...", "domain":"site.com"}
  Ответ: {"valid":true, "message":"Деактивирована"}
  Открепляет лицензию от домена для переноса.

GET /api/status
  Ответ: {"server":"KZM License Server", "status":"online"}

Все ответы содержат:
  - timestamp  — время ответа (unix)
  - signature  — HMAC-SHA256 подпись для верификации

Rate-limits:
  - activate:   10 запросов / 5 мин
  - verify:     60 запросов / 1 мин
  - heartbeat:  120 запросов / 1 мин
  - deactivate: 5 запросов / 5 мин

9. РЕШЕНИЕ ПРОБЛЕМ
================================================================

Проблема: Белая страница / 500 ошибка
  → Проверить PHP ≥ 8.0: php -v
  → Проверить расширения: php -m | grep pdo_mysql
  → Проверить права файлов: chmod 755 для папок, 644 для файлов

Проблема: 404 на всех страницах
  → Проверить что mod_rewrite включён
  → Проверить что .htaccess загружен

Проблема: "Ошибка подключения к MySQL"
  → Проверить параметры БД в config.php
  → Проверить что БД создана
  → Проверить что пользователь имеет права

Проблема: config.php доступен по URL
  → Проверить .htaccess
  → Добавить: <Files "config.php"> Require all denied </Files>

Проблема: Забыли пароль админа
  → В phpMyAdmin выполнить:
     UPDATE admins SET password_hash = '$2y$12$...' WHERE username = 'admin';
  → Хэш сгенерировать: php -r "echo password_hash('новый_пароль', PASSWORD_BCRYPT);"
